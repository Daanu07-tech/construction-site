🏗️ Construction Site Report System

A full-stack web application for managing construction site reports with image upload, PDF generation, and mobile-friendly UI.

---

🚀 Features

* 📋 Create site reports with multiple entries
* 📷 Upload images or capture from camera
* 📄 Generate professional PDF reports
* 💾 Save reports to database
* 📱 Mobile-friendly & installable (PWA)
* 🌐 Live deployment support

---

🧱 Tech Stack

Frontend
* HTML
* CSS
* JavaScript
* jsPDF (for PDF generation)

Backend
* Node.js
* Express.js

Database
* MongoDB / MongoDB Atlas

⚙️ Setup Instructions
1. Clone the repository
git clone https://github.com/your-username/construction-site.git
cd construction-site

2. Install backend dependencies
cd backend
npm install

3. Run backend server
node server.js

4. Open frontend
Open `index.html` or use Live Server in VS Code.

🌐 Deployment
* Frontend: Vercel
* Backend: Render
